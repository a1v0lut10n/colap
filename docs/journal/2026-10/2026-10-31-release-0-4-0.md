# COLA-0013: colap 0.4.0

## Context

Four tickets in two days since 0.3.0: comments (COLA-0009), exact
numbers (COLA-0010), the schema validator (COLA-0011) and the
generator from schemas (COLA-0012), closing the schema task. All four
break the 0.3 API, and the downstream migrations in aicogito and
chaiss wait on crates.io to take the 0.3 and 0.4 bumps together.

## Details

The release is a version bump, the changelog entry folded from
`Unreleased` with the breaking changes grouped by what a caller must
touch, and two stale version mentions fixed (the README still said
`colap = "0.1"`). The package was dry-run and listed: the meta-schema
and the schema corpus travel with the crate, the design history does
not. Crates generated with `--schema` default to `colap = "0.4.0"`,
so they build against crates.io from this release on.

After merge: tag `v0.4.0`, `cargo publish`, a GitHub release with the
changelog entry as notes.
