# COLA-0016: release colap 0.5.0

## Premise

Two tickets since 0.4.0, both from the first library consumer's field
test: the quiet parser on rustemo 0.9.1 (COLA-0014) and the `cli` and
`generator` features (COLA-0015). The rustemo re-export is a breaking
change for callers of the raw AST, so this is a minor release, not a
patch. The README's installation section already says 0.5 with the
feature table; the CHANGELOG's Unreleased section already holds both
entries.

## Action items

1. **Version** `0.5.0` in `Cargo.toml` and the lockfile; the schema
   spec's "as implemented by" line follows (the language spec names no
   version).
2. **`CHANGELOG.md`**: the Unreleased section becomes the 0.5.0 entry,
   dated, with an introduction; compare links for 0.5.0 and a fresh
   Unreleased.
3. **Housekeeping**: the 0.4.0 release plan is still `in-progress`; it
   is set done.
4. After merge, on `main`: tag `v0.5.0`, `cargo publish`, a GitHub
   release whose notes are the changelog entry. Then downstream: chaiss
   drops its `RUSTEMO_NOTRACE` guard, aicogito's lockfile unifies on
   rustemo 0.9.1.
