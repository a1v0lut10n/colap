# colap 0.3.0: the literate-format hardening batch released

## Context

Seven tickets (COLA-0001 to COLA-0007) answered the 2026-10-29 field
test of colap 0.2 in a literate knowledge repository. Together they
changed the public API and the language enough for a minor bump, and
aicogito SUM-0233 and chaiss CHAI-0044 wait on the crates.io release to
migrate.

## Details

0.3.0 is the first release with a changelog. Its entry is written from
the caller's side: what a 0.2 user must touch (the facade, the
`ModelBuilder` struct, the arena model, `ConfigValue`'s new variants
and decoded escapes, typed errors, the highlighter state, generated
crates without rustemo, the CLI subcommands), then what was added and
fixed. The one change of meaning in the language is escape decoding;
everything else is a superset of 0.2.

Release hygiene found on the way: the crate was packaging the whole
`docs/` tree and the workspace conventions, now excluded; the README
license section lacked the Apache Section 5 contribution note from the
workspace checklist. `cargo publish --dry-run` builds the package from
its own contents.

Remaining from the batch: comments (`//`, carried through `fmt`), the
last deliverable of the value-language task, and the schema design,
seeded by the incubation entry on temporal values released with this
change.
