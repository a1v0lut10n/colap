# COLA-0013: release colap 0.4.0

## Premise

Four tickets since 0.3.0 changed the language (comments, exact
numbers, schemas) and the public API (`ConfigValue::Number`,
`add_block` taking the block text, `Report::findings`, the schema
module, `generate --schema`). The schema task is closed. Downstream,
aicogito SUM-0233 and chaiss CHAI-0044 wait on the crates.io release
to take the 0.3 and 0.4 bumps in one pass, and crates generated with
`--schema` depend on the crate's own version, so they build against
crates.io only once it is published.

## Action items

1. **Version** `0.4.0` in `Cargo.toml`; the README's installation line
   (still `0.1`) and the language spec's "as implemented by" line
   follow.
2. **`CHANGELOG.md`**: the `Unreleased` section becomes the 0.4.0
   entry, dated, with an introduction, the breaking changes grouped by
   what a 0.3 caller must touch, then the additions; compare links for
   0.4.0 and a fresh `Unreleased`.
3. **Housekeeping**: the 0.3.0 release plan is still `in-progress`;
   it is set done.
4. After merge, on `main`: tag `v0.4.0`, `cargo publish`, and a GitHub
   release whose notes are the changelog entry; then the downstream
   plans can run.
