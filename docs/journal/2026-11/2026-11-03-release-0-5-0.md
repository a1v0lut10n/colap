# COLA-0016: colap 0.5.0

## Context

Two tickets since 0.4.0, both answering the first library consumer's
field test of 2026-11-01: the quiet parser on rustemo 0.9.1
(COLA-0014) and the `cli` and `generator` features (COLA-0015). The
language is unchanged. The rustemo re-export is a breaking change for
callers of the raw AST, which makes this a minor release.

## Details

The release is a version bump, the changelog entry folded from
Unreleased with an introduction naming the consumer that drove it, the
schema spec's "as implemented by" line, and the 0.4.0 release plan
set done. The package was dry-run and listed: 141 files, the
quiet-parser test travels with the crate, the design history does
not. A crate generated without `--colap-path` names
`colap = { version = "0.5.0", default-features = false }`, so it
builds against crates.io with the library alone from this release on.

After merge: tag `v0.5.0`, `cargo publish`, a GitHub release with the
changelog entry as notes. Then downstream: chaiss drops the
`RUSTEMO_NOTRACE` guard in its main, and aicogito's lockfile unifies
on rustemo 0.9.1 when it next bumps colap.
