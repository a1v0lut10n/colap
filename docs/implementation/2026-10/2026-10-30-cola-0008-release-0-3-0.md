# COLA-0008: release colap 0.3.0

## Premise

Seven tickets since 0.2.0 changed the public API (the facade, the
typed errors, the arena model, the highlighter state, the value
variants) and the language (fences, duplicate rules, decoded escapes,
the value forms). Downstream, aicogito SUM-0233 and chaiss CHAI-0044
wait on the crates.io release to migrate. 0.2.0 is on crates.io and
tagged; there is no changelog and no GitHub release yet.

## Action items

1. **Version** `0.3.0` in `Cargo.toml`, with an `exclude` list so the
   published crate carries the code, tests, bench and README images but
   not the workspace conventions or the design history.
2. **`CHANGELOG.md`**, Keep-a-Changelog style, with the breaking changes
   grouped by what a 0.2 caller must touch, the additions, and the
   fixes; a 0.2.0 entry for the baseline.
3. **README license section** gains the Apache Section 5 contribution
   note, per the workspace open-source checklist.
4. **Carried along**: the incubation entry on temporal values written
   after the value-language discussion.
5. After merge, on `main`: tag `v0.3.0`, `cargo publish`, and a GitHub
   release whose notes are the changelog entry.
